# EcoRota Curitiba ♻️

## Sobre o Projeto
O EcoRota Curitiba é uma plataforma web modular de baixo custo voltada a otimizar a logística reversa e a gestão descentralizada de resíduos recicláveis na capital paranaense, conectando condomínios e pequenos comércios a catadores e cooperativas locais.

## Stack Tecnológica
* **Frontend:** HTML5, Tailwind CSS, JavaScript
* **Mapeamento:** Leaflet.js + OpenStreetMap / Esri Tiles
* **Banco de Dados (Planejado):** Supabase
